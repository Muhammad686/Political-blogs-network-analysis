# SNTP Assignment 1

This repository contains the notebook and supporting files for the SNTP Assignment 1 analysis.

## Contents
- `SNTP_ASSIGN_1.ipynb`: main analysis notebook
- `requirements.txt`: Python dependencies required to run the notebook
- `.gitignore`: local workspace and Python file exclusions

## Setup
1. Create and activate a Python environment.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Open `SNTP_ASSIGN_1.ipynb` and run the cells in order.

## Notes
- The notebook performs preprocessing, graph construction, centrality analysis, targeted/random removal experiments, and Louvain community evaluation for the `polblogs` dataset.
- Generated outputs and temporary files are intentionally excluded from version control.
